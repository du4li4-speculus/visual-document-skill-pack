# Content Production Project Template

## Purpose

Create reusable workflows for professional educational and research outputs.

## Structure

```
content-production/

├── source/
│   Research and raw materials.
│
├── structure/
│   Outlines and information architecture.
│
├── assets/
│   Charts, diagrams, images.
│
├── production/
│   Documents, slides, HTML.
│
└── review/
    Quality checks.
```

## Workflow

```
Research
 ↓
Information architecture
 ↓
Visual design
 ↓
Production
 ↓
QA
```

## Rules

- Structure before aesthetics.
- Use diagrams when relationships matter.
- Use visuals only when they improve understanding.
- Keep source evidence connected.

## Suitable Projects

- school reports
- strategy decks
- teaching materials
- public-facing documents
