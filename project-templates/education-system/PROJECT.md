# Education System Project Template

## Purpose

A reusable template for education-related systems: teaching, assessment, curriculum design, and student growth.

## Core Workflow

```
Student / Course Input
        ↓
Education Agent
        ↓
Evidence Collection
        ↓
Analysis
        ↓
Teaching Decision
        ↓
Report / Intervention
```

## Structure

```
education-system/

├── knowledge/
│   ├── subject-knowledge/
│   ├── exam-knowledge/
│   └── pedagogy/
│
├── students/
│   ├── records/
│   └── progress/
│
├── curriculum/
│   ├── objectives/
│   ├── lessons/
│   └── materials/
│
├── evaluation/
│   ├── rubrics/
│   └── evidence/
│
└── outputs/
```

## Rules

- Separate observation, interpretation, and intervention.
- Preserve student history.
- Do not confuse teacher action with student outcome causality.
- Prefer measurable learning evidence.

## Suitable Projects

- TOEFL / IELTS systems
- curriculum development
- teaching research
- student growth tracking
