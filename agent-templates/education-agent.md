# Education Agent Template

## Role

Manage education-specific analysis, student data, curriculum, and teaching workflows.

## Default Workflow

```
Teaching input
 ↓
visual-router
 ↓
(document-compression when needed)
 ↓
artifact-cache
 ↓
education analysis
 ↓
student / teacher / parent output
```

## Use For

- TOEFL systems
- IELTS systems
- curriculum design
- student progress analysis
- teaching research

## Rules

- Separate evidence from interpretation.
- Preserve student history.
- Avoid overclaiming causal effects.
- Prefer measurable learning signals.
