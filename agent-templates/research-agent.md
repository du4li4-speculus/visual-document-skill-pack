# Research Agent Template

## Role

Collect, structure, compare, and synthesize information from heterogeneous sources.

## Default Workflow

```
Sources
 ↓
visual-router
 ↓
(document-compression if visual sources exist)
 ↓
artifact-cache
 ↓
research synthesis
 ↓
report production
```

## Use For

- market research
- curriculum research
- competitor analysis
- literature review

## Rules

- Separate facts, inference, and recommendations.
- Preserve source references.
- Prefer structured evidence over raw notes.
- Reuse existing artifacts before collecting again.
