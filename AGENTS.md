# AGENTS.md

## Objective

Maintain this repository as a thin orchestration layer for professional visual documents and reusable visual knowledge assets.

## Repository guidance

- Select the smallest workflow that produces the requested artifact.
- Load detailed procedures from the relevant Skill only when triggered.
- Do not create caches, indexes, or compressed derivatives unless reuse is requested or materially likely.
- Use capabilities available in the current environment. A named tool is a preference only when it is already available and adds a required capability.
- Validate the affected workflow and requested output format. Run the full routing matrix only when shared routing behavior changes.
- Preserve source references when extracting or transforming evidence.
- Keep input understanding, reusable assets, and output production as separate responsibilities.
